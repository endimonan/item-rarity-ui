[h1]What does this mod do?[/h1]
Adds colored item names and a rarity column to your inventory, based on actual spawn chances from the game's loot tables.

Ever looted a house and wondered how lucky you actually got? This mod calculates the real drop weight of every item across all procedural distributions and assigns a rarity tier - right there in your inventory.

[h1]How it works[/h1]
Rarity is based on how often an item actually shows up across all loot sources. The lower the weighted spawn chance, the rarer it is. Simple as that.
[list]
[*][b]Legendary[/b] (orange) - The stuff you almost never find.
[*][b]Epic[/b] (purple) - Rare items worth celebrating.
[*][b]Rare[/b] (blue) - Solid finds. Worth holding onto.
[*][b]Uncommon[/b] (green) - Shows up sometimes, nothing crazy.
[*][b]Common[/b] (gray) - You'll trip over these in every kitchen and bathroom.
[*][b]Crafted[/b] (cyan) - Items only obtainable through crafting.
[/list]
Items that don't appear in any loot table show as Unknown.

[h1]Features[/h1]
[list]
[*]Colored item names by rarity (RPG-style)
[*]Show or hide column via menu
[*]Dedicated "Rarity" column in the inventory panel
[*]Click the column header to sort items by rarity
[*]Resizable column - drag to adjust like other columns
[*]Dynamic width for different screen resolutions (Steam Deck friendly)
[*]Separate rarity data for B41 and B42 loot tables
[*]Safe to add to existing saves - no new game required
[/list]
